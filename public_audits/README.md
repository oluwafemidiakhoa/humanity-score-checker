## Verification

Each audit directory contains the disclosed evidence and a deterministic report hash. The full audit record includes source URLs, evidence gaps, limitations, correction policy, and methodology version.

Machine-readable cohort metadata is available in [index.json](./index.json).

## Interpretation

A higher or lower score should not be read as an unsupported overall product ranking. Humanity Score evaluates a defined rubric from the evidence supplied or documented at the audit date. Missing evidence remains visible rather than being silently inferred.

## Corrections

Source-backed factual corrections are welcome. Payment cannot buy a higher score; a score changes only when the underlying evidence or methodology changes.
