## Evidence used

### Agency / user_control
Organization owners can enable or disable Copilot features, agents, and models through organization policies, and can grant or revoke access for members.

Source: https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-organization/manage-policies?tool=vscode

### Agency / reversibility
Organizations can revoke Copilot access for members and disable individual Copilot features or models through organization and enterprise policy controls.

Source: https://docs.github.com/en/copilot/how-tos/administer-copilot/manage-for-organization

### Agency / transparency
GitHub documents which Copilot data types are processed, how organization policies work, and how model and usage controls are configured.

Source: https://github.com/features/copilot/plans

### Agency / human_override
GitHub states that inline Copilot suggestions are only applied when the user explicitly accepts them, and users are responsible for reviewing and validating generated suggestions.

Source: https://docs.github.com/en/copilot/responsible-use/inline-suggestions

### Value Distribution / user_benefit
GitHub publishes free and paid Copilot plans with included features, usage allowances, and support for individual, business, and enterprise users.

Source: https://github.com/features/copilot/plans

### Value Distribution / data_rights
Copilot Business and Enterprise administrators can configure content exclusion so specified files are ignored by Copilot and not used for inline suggestions, responses, or code review.

Source: https://docs.github.com/en/copilot/concepts/security-governance-and-network-settings/content-exclusion

### Value Distribution / lock_in
GitHub Copilot is available across multiple IDEs, GitHub, mobile, CLI, and supports model choice and third-party agents, reducing dependence on a single interaction surface.

Source: https://github.com/features/copilot

### Value Distribution / incentive_alignment
GitHub publishes plan prices, included AI-credit allowances, usage billing rules, and budget controls that can limit additional paid Copilot usage.

Source: https://docs.github.com/en/enterprise-cloud@latest/billing/concepts/product-billing/github-copilot-billing

### Human Connection / collaboration
Copilot integrates with pull requests, code review, shared repositories, and organization workflows where review comments can be discussed and resolved by team members.

Source: https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/copilot-code-review

### Human Connection / substitution_risk
GitHub's responsible-use guidance says Copilot should be used as a tool rather than a replacement for human programming and emphasizes review, testing, and human oversight.

Source: https://docs.github.com/en/copilot/responsible-use/inline-suggestions

### Human Connection / accessibility
GitHub offers a free Copilot plan with no credit card required and provides no-cost access to premium Copilot features for verified students.

Source: https://github.com/features/copilot/plans
